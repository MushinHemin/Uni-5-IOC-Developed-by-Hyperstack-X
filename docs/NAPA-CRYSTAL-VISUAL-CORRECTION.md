2026-11-09。本轮仅精修现有首页三卡；不修改登录、聊天、菜单、弹窗、业务协议或真实数据。所有改动保持未提交。

## 渲染路径与根因

开始时 `design/napa-valley-optical-prototype @ b8c177c` 有此前未提交成果；diff check 无错误，rejected-design stash 保留。8860 旧预览已不响应，本轮在 **8862** 启动隔离合成预览，避免把旧页面误当成新结果。

实际检查三张卡片均为 `crystal-ready`，无 `crystal-fallback`。路径为 **共享 WebGL 1 → 2D 展示画布**。已知 Sonoma 图片为 2400×2400，上传纹理 2048×2048，线性过滤；CSS cover、背景负 inset、缩放与屏幕位置仍按原映射计算。DPR 2 时画布采样上限为 1.5×，但位移仍使用 CSS 像素，没有再除以 DPR。

原实现有两处削弱观感：

- 旧 `dispersion=.65` 在直边又乘 `.25`，红蓝总分离仅约 **0.325 CSS px**，很容易被线性采样和显示缩放平滑掉。
- 核心漫射从折射带中间开始混入未位移的采样，降低内侧折射的清晰度。旧高光也偏窄，无法形成足够宽的曲面体积。

本次重新分配有效位移区和光照区，**没有把“增大一个强度数字”当作完成标准**。旧版直边参数 12px 也不等于整条边缘具有 12px 的可见位移。

## 最终参数

以下为默认玻璃强度 50%、100% 缩放时的 CSS px；自然档是默认候选，尚待负责人审美验收。

|参数|自然档|夸张调试档|
|---|---:|---:|
|折射带宽|22|24|
|直边峰值采样位移|6|16|
|圆角峰值采样位移|12|28|
|圆角红蓝通道总分离峰值|3|7.2|
|直边红蓝通道总分离峰值|1.5|3.6|
|曲面光照系数|1|1.8|

红蓝总分离 3px 表示 R/G/B 为约 `+1.5 / 0 / -1.5px`；不是三个通道各偏移 3px。色散仅出现在高折射区域，按法线方向和圆角曲率变化，没有增加彩色描边。

用户玻璃偏好继续生效，自然档最终峰值被限制在直边 6px、圆角 12px 以内。调试档只由显式预览参数或根元素 `data-crystal-profile="debug"` 启用，不自动启用、不持久化。

## 改变了什么

1. 位移沿外侧约 23% 的带宽逐渐建立，在约 23%–43% 保持，然后平滑回到中央的零位移。直边与圆角独立标定。
2. 将核心漫射移到折射带之后，避免把折射采样混回原位置。
3. 光学边缘包含窄外轮廓、宽曲面反射、内侧暗部和弱反向反射，主要厚度分布在约 18–22px。沿用原来的局部动态高光。
4. 全部新增光照在折射带内归零。首次夸张档检查发现的中央明暗分块已修正，并增加“关闭边缘光照时中央像素不变”的检查。
5. 保留原来的局部亮度保护、文字颜色选择与原生文字渲染。没有改变卡片尺寸、排版、壁纸和蓝色入口图标。

仍是对**已知 Sonoma 壁纸**的图像空间折射；不采样任意背后 DOM，不宣称物理光线追踪。

相邻行的偏移连续变化；记录保存了完整采样路径。折射、色散和边缘光照在距边缘 42px 以上的中央采样区，开关前后的最大通道差均为 **0**。
