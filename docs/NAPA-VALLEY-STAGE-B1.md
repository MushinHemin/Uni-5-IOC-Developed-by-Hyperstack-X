## 材质纠偏与范围

没有更换壁纸、重做导航、移动功能入口或调整主布局。改动限于材质、背景光照、圆角和统一的光学响应；主窗口、首页三张卡片、聊天输入区优先校准，共享材质同步覆盖登录、导航和既有菜单/弹窗。论坛、用户内容与业务功能没有重写。

### 1. Wallpaper：取消全屏白雾

原先 `body::before` 将景观图与白色渐变叠加，再使用 10px 模糊；`body::after` 又覆盖白色径向和线性渐变。多个内容容器继续叠白，造成颜色被洗淡。

现在仍读取 `/assets/backgrounds/sonoma.jpg`，全屏仅保留 **1px 轻微模糊**，不再降低壁纸饱和度或用白色覆盖全屏。浅色主题底部使用最高 3.5% 的深色微调，深色主题使用 12% 深色环境遮罩；不另换图片，也不再将深色主题背景亮度直接压到 0.58。

登录时后方应用的景深仍存在，它作用于后景 UI，不等于模糊整张壁纸。透明窗口揭露了原先退后的聊天文字，因此在其他前景页面激活时，对后方聊天平面使用 16px（窄屏 8px）漫射，保留空间关系而不让两层正文互相干扰。

### 2. Clear Edge · Frosted Core

每个主要玻璃容器只有一个绝对定位、`aria-hidden`、`pointer-events:none` 的 `.napa-material-core` 装饰层，不参与 Grid/Flex 排版。外层是清透底色，内部使用正交渐变遮罩交叠形成连续的圆角矩形过渡，不是圆形白色斑块。

- **外缘**：低 Alpha 基底，取消整个容器的均匀 backdrop-filter。
- **过渡**：沿容器横纵方向逐渐增强核心遮罩，默认约 10% 羽化，卡片约 16%。没有硬切换线。
- **核心**：一次局部 backdrop-filter 加半透明阅读底色；文本、按钮和图标不参与整体 opacity 或色散。
- **叠层控制**：删除侧栏、聊天头和窗口内部的多余均匀白底/采样。首页卡片位于窗口核心之上，其核心 tint 再减半，避免重复磨砂。窄屏卡片取消第二次 backdrop 采样，保留阅读 tint。

玻璃滑块保持原有存储键与缺省 **50%**，用户显式保存的 **0%** 仍然有效。`applyGlassIntensity` 只调整展示参数，没有改变认证、消息、通知或草稿逻辑。

|强度|浅色结构外缘 Alpha|浅色窗口核心 Alpha|浅色卡片附加核心 Alpha|核心 blur|
|---|---:|---:|---:|---:|
|0%|0.06|0.22|0.11|6px|
|50%|0.12|0.33|0.165|11px|
|100%|0.18|0.44|0.22|16px|

深色阅读核心为 0.58–0.74，卡片附加核心为其一半。深色核心更强是为了保护明亮壁纸上的浅色文字，不把这一范围当作所有容器的统一透明度。消息气泡保留原来的局部阅读保护；首页文字区有小范围渐隐的保护底色，辅助文字颜色加深。

### 3. Living Specular Highlights

光学轮廓使用 1px masked rim；动态光照限制在约 5px 的边缘带。冷暖色散只在窄边缘出现，文本、图标和媒体不参与。

- 指针靠近边缘时，光点投影到最近边缘，亮度随距离变化；采用基于时间的非线性插值，不直接跳到鼠标位置。
- 离开时，用最长 700ms 回到默认环境光方向，再移除临时变量；静止后停止 RAF。
- 全局只有一个委托 pointermove 与一个共享 RAF，最多维护一个当前表面和两个回落中的表面；进入新表面时才读取矩形，高频移动不逐帧读布局。
- 按压时局部高光宽度收窄，操作控件小幅压缩，松开/取消恢复；结构窗口不跟着压缩。
- 滚动、窗口尺寸变化、失焦、后台与 reduced-motion 会取消跟踪。触屏不模拟鼠标高光，保留按压反馈。
- 没有永续闪烁、全屏位移滤镜或逐像素光线计算。**Lensing、色散和边缘位移仍为可控的视觉近似，不是物理折射。**

### 4. 圆角体系

桌面主窗口约 48px、首页大卡片约 40px、登录/弹窗约 42px；菜单和输入容器 28px；小按钮、标签、导航指示器使用胶囊形。多行输入框保留 22px 圆角，避免巨大胶囊端部吞掉输入空间。

窄屏：卡片 30px、弹窗 32px、输入/导航 26px。原本全屏贴边的移动主窗口仍为 0px，避免为了圆角改变布局或安全区域。按钮可见性、权限、尺寸和事件入口不变。

- 最终卡片附加 tint 减半后，浅深色 **2/2 项定向检查通过**，首页截图重新生成。
- 原有 U19 / 消息可靠性关联测试 **14/14 通过**，使用隔离 Node 24.22.1。没有反复运行无关全套测试。
- JavaScript 与内联脚本语法、`git diff --check` 通过。
- 保存 **16 张截图**：12 张浅深主题前后对照、3 张高光状态特写、1 张移动截图。`comparison.html` 可拖动比较 Stage B 与 B.1。
- 30 次空闲 RAF 采样，间隔中位数和 P95 均约 16.7ms；这只是本机 Headless Edge 156.0.4314.50 的观察，不是实际设备帧率、滚动性能或触控延迟认证。受测输入和导航成功，没有据此保证所有设备无卡顿。

**未完成**：Safari/iPhone 实测、真实软键盘、PWA 独立窗口、真实 GPU/功耗分析、复杂媒体长列表压力，以及全站逐元素 WCAG 对比度测量。采用 WebKit 前缀与渐进降级不等于 Safari 已验证。

不支持 mask 时去掉增强边缘、保留普通磨砂核心；不支持 backdrop-filter 或需要高对比度时使用不透明可读材质。低端 Safari 的多层合成成本仍需实际设备验收。
