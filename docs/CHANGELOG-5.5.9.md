# Uni 5 Sonoma 5.5.9
## Reliability & Security Update

**日期：2026-11-07 · 基准版本：5.5.8 · 范围：可靠性、安全边界、数据完整性与定向交互修复**

本次更新保留 Sonoma 液态玻璃、主题、动画、Community Workspace 与既有社交功能。以下内容描述源码变更，不代表已部署运行，也不代表已创建 GitHub Release 或通过完整发布验收。

> **验证声明：最终 UI/输入法修改未经本轮测试验证。** 本轮按维护者要求未执行自动化测试、回归测试或浏览器端到端测试。此前阶段的验证结果仅代表相应阶段，不能替代本次最终版本验证。

### 已知限制与升级注意

- 新前端发送确认应配套新后端；无请求 ID 的旧客户端不能获得重试去重保证。待确认请求仅在页面内存中保留。
- 图片隔离仍占磁盘空间，未新增永久销毁政策或公开恢复入口。`image-quarantine/` 与数据库、上传内容一样不应提交 Git。
- 评论为逻辑删除，原正文在数据库保留；任意历史坏关系、旧孤立记录不会在启动时批量销毁。
- 已有非空 SQLite 不自动合并旧 JSON；真实升级前应完成一致的数据库/WAL 与附件备份并验证恢复。
- 历史分页协议已具备，现有 UI 尚无自动加载更早消息的滚动入口。
- 已有弱管理员密码不会自动轮换；反向代理下邀请码尝试额度可能被多个用户共享。Token 固定 TTL 与持久重连机制仍待完善。
- 本次没有部署真实服务、迁移真实数据库、删除真实用户内容或修改 Git 历史；没有推进 Android/Capacitor 开发。
