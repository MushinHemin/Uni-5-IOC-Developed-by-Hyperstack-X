## U19 · 实施完成，实机验收待完成

`public/index.html` 中统一移动端布局的导航内容高度、间距、安全区域和可见视口：

- 取消聊天页把导航抬高 82px 的规则，聊天容器为底部导航保留实际空间；移除消息列表重复预留的导航高度。

- 聚焦聊天且可见高度明显缩小时，暂时收起导航与侧栏；短横屏隐藏侧栏但保留聊天头部操作，限制输入框高度。长标题/副标题省略显示，避免挤压消息列表。

键盘识别采用“聚焦 + 相对高度变化”规则，浏览器没有统一的键盘可见 API，浮动键盘和特殊辅助功能需实机验收。container query / dynamic viewport 的旧浏览器支持也不在本轮保证范围。
